## GitHub Pages settings

- Publishing source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Custom domain: **www.francovanniekerk.com**
- HTTPS: **Enforce HTTPS**

The `.nojekyll` file must remain in the repository root so GitHub publishes the `_next` asset directory.
